# Security Policy

## Reporting a Vulnerability

Please report security issues privately to **nick.kovac@targetcast.jp**.

Include a description of the issue, steps to reproduce, and the affected
version. You should receive a response within a few days. Please do not
open public GitHub issues for security vulnerabilities.

## Scope

This server executes a headless Chromium (via `@mermaid-js/mermaid-cli`)
to render diagrams. Reports about sandbox escapes, arbitrary file access
through tool parameters, or command injection via diagram syntax are
especially welcome.
